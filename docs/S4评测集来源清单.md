# S4（媒体/电子人声）评测集：公开来源清单

> 结论先说：**没有现成的"S4 拒识"公开评测集**。能拿到的只有"媒体人声素材"，需要自己切段、标成 S4。
> 本文列清可用来源、许可、体积、能覆盖什么、缺什么，以及落地命令。
> 版本：v1.0　｜　日期：2026-11-03

---

## 1. S4 到底要测什么

| 项 | 要求 |
|---|---|
| 输入 | 电视/剧集/综艺/短视频外放/播客/语音播报/导航播报 里的**人类语音** |
| 正确行为 | 不响应（`silent`），且**不调用任何工具** |
| 高危子集 | **指令式台词**（"打开空调""把枪放下""放首歌"）——最容易误触发 |
| 判据 | S4 拒识率 ≥95%，误执行 = 0 |

难点：素材好找，**"该不该响应"的 gold 好标（全标 silent）**，但"真实客厅声学 + 多房间 + 指令式台词"三者同时具备的公开数据不存在。

---

## 2. 可用来源（全部实测可下载）

| 来源 | 内容 | 体积 | 许可 | 语言 | 能覆盖 |
|---|---|---:|---|---|---|
| **WenetSpeech**（OpenSLR SLR121） | 中文多域：影视/综艺/新闻/访谈/有声书等 | 10,000+ h 高置信 + 2,400 h 弱标 + ~10,000 h 无标（音频共 22,400+ h） | CC BY 4.0 | 中文 | **中文媒体人声首选**（需申请） |
| **MediaSpeech**（OpenSLR SLR108） | 电视/广播新闻语音，人工转写 | 每语种 ~600 MB（FR 637 / AR 611 / TR 618 / ES 582） | CC BY 4.0 | 法/阿/土/西 | 真实广播电视人声（**无中文**） |
| **CN-Celeb v2**（OpenSLR SLR82） | 中文 in-the-wild：影视/综艺/访谈片段，1,000+ 说话人 | **22 GB**（单包） | CC BY-SA 4.0 | 中文 | 中文媒体人声（最贴 S4，但体积大、无"是否对设备说"标签） |
| **MUSAN**（OpenSLR SLR17） | music / speech / noise 三类 | 11 GB（music 子集约 3 GB） | 见 MUSAN 说明 | 无语言 | 外放音乐、歌声、嘈杂背景（做干扰而非主体） |
| **AudioSet**（Google） | YouTube 527 类事件（含 Television / Music / News） | 标签 ~1.7 GB，音频需 yt-dlp | 标签 CC BY 4.0；音频受 YouTube 条款 | 多语 | 可挖"电视在响"的真实片段；**合规风险高**，仅内部 |
| **CHiME-6/7、DiPCo** | 家庭聚餐场景，含电视背景 | 数十 GB | 研究许可（需签署） | 英 | 真实家庭声学 + 电视噪声（但电视人声不是主体） |

> 已核查的关键限制：
> - MediaSpeech 只有 4 个非中文语种 → 只能当"真实媒体人声"的旁证，不能当中文结论
> - CN-Celeb 是**说话人识别**用途，片段来自媒体但**没有"这句是对谁说的"标注** → 只能整体标 S4
> - MUSAN 的 music 是纯音乐/歌声，**不含台词**，做不了"指令式台词"对抗子集

## 2.5 WenetSpeech：目前最贴 S4 的中文公开来源

| 项 | 内容 |
|---|---|
| 规模 | 10,000+ h 高置信标注 + 2,400 h 弱标（0.6≤conf<0.95）+ ~10,000 h 无标；**音频共 22,400+ h** |
| 语言 | 普通话（YouTube + Podcast 采集，OCR/ASR 双路打标） |
| 许可 | **CC BY 4.0**（比 CN-Celeb 的 CC BY-SA 更宽松，商用友好） |
| 粒度 | **逐句切好**，带转写与置信度；不用自己切段 |
| 域分布（高置信） | drama **43.36%**、reading 11.1%、interview 9.38%、news 8.68%、variety 8.27%、documentary 4.77%、talk 2.94%、audiobook 2.51%、commentary 2.48%、others 6.51% |
| 访问 | 需在 <https://wenet.org.cn/WenetSpeech> 填 Google 表单拿解压密码；HF 上同名集为 gated |
| TTS 版 | **WenetSpeech4TTS**（12,800 h，按切片质量分档，HF gated）——切片更干净，适合做"台词"素材 |

**为什么它比另外两个源更适合 S4**：

1. **中文 + 媒体为主**：drama/variety/news/documentary/commentary/talk 加起来约 **77%**，正是电视/剧集/综艺那类"电子人声"
2. **逐句切片**：省掉自己切段的工程，直接按 utterance 取样
3. **置信度可用**：只要 conf ≥0.95 的高置信段，避免把转录噪声当评测噪声
4. **许可干净**：CC BY 4.0，署名即可

**它仍然缺什么**：

| 缺口 | 说明 |
|---|---|
| 无"这句对谁说"标签 | S4 本来就全标 silent，不影响判分 |
| 域标签可能在语料级而非逐句 | 需要按目录/元数据确认；取 drama 等目录最省事 |
| 单品几十 GB | 无法只下 300 条；建议先下 test/dev 或按官方分包 |
| 需人工申请 | 拿密码这一步只能你做 |

## 3. 三种取材路线（按可信度与成本）

| 路线 | 做法 | 规模 | 成本 | 适合 |
|---|---|---|---|---|
| **A 公开素材直采** | **WenetSpeech（中文，首选）** + MediaSpeech（跨语种旁证）+ CN-Celeb（备用），全标 S4 | 200–600 段 | 中文需申请、体积几十 GB | 冒烟、中文真实媒体人声 |
| **B 台词 + TTS 合成** | 从字幕/剧本取"指令式台词"，TTS 生成，再与 MUSAN 音乐/噪声按 SNR 混音，可选 RIR 卷积成远场 | 100–200 段 | 几乎为 0 | **指令式台词对抗子集**（唯一可控来源） |
| **C 真实客厅自采** | 电视/音箱外放 2 m，200 段，标 `has_imperative_phrase` | 200 段 | 3 天人力 | 验收（见《S4媒体人声冒烟方案.md》） |

**建议组合**：A（真实声学、跨语种）200 段 + B（指令式台词）100 段 = 300 段冒烟；验收仍以 C 为准。

## 4. 落地命令

已封装：`tools/s4_fetch.py`

```bash
# 只看链接与体积（不下载）
python3 tools/s4_fetch.py --source mediaspeech --lang FR --out data/s4 --dry-run
python3 tools/s4_fetch.py --source cn-celeb --out data/s4 --dry-run

# 下载 + 解包 + 生成 S4 manifest（MediaSpeech 法语，约 637 MB）
python3 tools/s4_fetch.py --source mediaspeech --lang FR --out data/s4 --build-manifest

# 中文（22 GB，建议放外接盘）
python3 tools/s4_fetch.py --source cn-celeb --out /Volumes/ext/s4 --build-manifest

# WenetSpeech：先申请密码并下载，再从本地目录建 manifest（可按域过滤）
python3 tools/s4_fetch.py --source wenetspeech --from-dir /path/to/wenetspeech \
  --out data/s4 --category drama          # drama / news / variety / documentary / audiobook / talk / commentary / interview
```

`--category` 只保留路径里含该关键词的音频；实测（用 185 个 flac 模拟 drama 目录）生成 manifest 185 条，`gold_scene=S4`、`gold_action=silent` 全部正确。

生成的 manifest 字段（与尺子1 完全同构，可直接喂 `llm_judge.py` / `score.py`）：

```json
{"id":"s4-3f9a1c2b7d4e","dataset":"s4_public","split":"test",
 "audio_root":"/abs/data/s4","audio":"mediaspeech/FR/xxx.wav",
 "gold_action":"silent","gold_scene":"S4","gold_lang":"fr",
 "meta":{"source_type":"media","segment_sec":20,"has_imperative_phrase":null},
 "audio_ok":true}
```

跑法与尺子1 一致：

```bash
python3 tools/llm_judge.py --manifest data/s4/s4_mediaspeech_FR.jsonl --backend openai_compat \
  --model qwen-plus --text-mode last --prompt-version v3 --out predictions/qwen-plus__s4.jsonl
python3 tools/score.py --manifest data/s4/s4_mediaspeech_FR.jsonl \
  --pred predictions/qwen-plus__s4.jsonl --only-predicted
```

## 5. 已知缺口（必须写进结论）

| 缺口 | 影响 | 补法 |
|---|---|---|
| 无中文公开"媒体人声 + 指令式台词" | 中文 S4 结论只能用合成或自采 | B 路线 + C 路线 |
| CN-Celeb 无"对谁说"标签 | 只能整段标 silent，不能细分 | 不影响 S4 判定（S4 全是 silent） |
| MediaSpeech 是新闻播报，语速平稳 | 比电视剧/短视频更"干净"，会**高估**拒识率 | 用短视频外放素材补（自采） |
| 无远场/混响真值 | 声学分布与客厅差一截 | RIR 卷积重放，或 C 路线 |
| 公开集无"误执行"标签 | 误执行只能靠我们自己的工具集判 | 用尺子1 的 score.py 已支持（工具调用即误执行） |
