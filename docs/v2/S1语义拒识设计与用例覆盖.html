S1 语义拒识：判定设计、场景清单与用例覆盖

版本 v1.0 · 2026-11-18 ｜ 上位文档（duplex-voice 仓库）：docs/S1场景判定与评测用例设计.md（总框架）、docs/拒识sideTalk设计文档.md §1.3（场景定义）
本篇只解决一件事：在"说话人是主用户"已确定之后，怎么用语义判断这句话指向谁——以及怎么测出这一步到底有没有用。

1. 语义层的位置：它只回答一个问题

1.1 三层分工（不要越界）

层 回答的问题 输入 失败后果 能否单独成立
身份层（声纹） 说话人是不是机主 音频 把家人当机主 / 把机主当访客 能（S2/S3 的主判据）
语义层（本篇） 这句话指向设备还是指向人 partial ASR 文本 + 会话上下文 + 系统状态 把旁白当指令（误响应）/ 把指令当旁白（漏响应） 不能——S1 与 S0 文本同形，语义只能给概率
空间层（DoA/近讲） 说话人朝向谁 多麦 / 双麦信号 同上 不能（朝向 ≠ 受话）

三条硬规矩：

  1. 语义层不判"该不该现在说"——那是语义 VAD / 轮次决策的事（附和、停顿、抢话）。本文与 docs/语义VAD方案.md 的分工：那边管时机，本文管对象。
  2. 语义层不单独定案。它的输出是 P(addressed) + 证据列表，由融合层决定动作（见 §3.3）。
  3. 语义层必须可解释：每条判定要能吐出"因为出现了称呼 X、谓词 Y、且未承接系统上一句"——否则上线后无法定位误判。

1.2 语义拒识的目标指标（单独考核，不含声学）

指标 定义 目标 说明
同形集准确率 在"文本与 S0 完全同形"的子集上的判对率 ≥ 92% 这是语义层唯一有意义的成绩；全集的 90% 可能被易样本拉高
语义召回（应静默被识别） S1 语义正例中判为"指向人"的比例 ≥ 95% 与身份层串联后的端到端拒识率另算
语义精确（判静默中真该静默） 判为"指向人"的样本中真为 S1 的比例 ≥ 90% 低了会吞真指令（FRR 上升）
clarify 率 语义低置信走确认的比例 ≤ 2% 高了用户嫌啰嗦
语义判定耗时 partial ASR 首个可用片段 → 语义输出 ≤ 100 ms 总静默预算 390 ms 内

2. 语义证据体系：八类证据，各有强弱

# 证据 判据（可操作） 典型句 反例（易混） 强度 可单独定案
E1 称呼 / 第二人称指称 出现"妈/爸/宝宝/老公/老婆/你/您/你们/老王"等人名或亲属称谓，且不在唤醒词典内 "妈，把盐递我" "小X，把盐递我"（唤醒词，不是称呼） 强 能（+人—人谓词更稳）
E2 人—人动作谓词 递/拿/放/收/抱/接/穿/吃/喂/哄/看孩子/帮我个忙 "你先把衣服收了" "把音量收到 20"（设备动作） 中—强 不能单独
E3 设备动作谓词 播放/暂停/下一首/音量/亮度/温度/导航/打电话/设闹钟/查天气 "把空调调到 26 度" "把空调遥控器递我"（人对人） 中—强（反向） 不能单独
E4 话语衔接 承接系统上一句（答句、补充槽位、追问） 系统问"要几度？"→"26" 冷启动说"26 度" 强（指向设备） 能（→ S0）
E5 指代与省略 "它/这个/那个" + 前文有实物指称 "这个帮我放桌上" "把它关了吧"（无前文，歧义） 弱—中 不能
E6 言语行为 请求 / 命令 / 告知 / 抱怨 / 复述 / 转述 "他说把灯关了"（转述） "把灯关了"（直述，对设备） 中（转述强指人） 转述可单列
E7 互动标记 呼唤—应答对（"老张——""哎"）、称呼后停顿 ≥300 ms "老张——""哎，来了" "小X——"（唤醒） 强 能（呼应对）
E8 话题与任务状态 当前槽位是否待填、话题是否延续 待填"关哪个灯"→"客厅" 无槽位时"客厅" 弱（先验） 不能

三条组合规律（规则基线可直接用）：

  • E1 + E2 → 高置信 S1（覆盖多数 F1 类样本）
  • E3 + E4 → 高置信 S0（覆盖真指令与答句）
  • E6（转述）+ E3 → 仍是 S1（"他说把灯关了"不是让我关灯）——这是最容易翻车的一类
  • 只有 E5 或只有 E8 → 不得定案，进 clarify

3. 判定架构：规则基线 → 小模型 → LLM 复核

3.1 三档结构（按代价从低到高，按需触发）

partial ASR 文本（≤300 ms 内首个可用片段）
        │
        ├─ 档 A｜规则基线（必跑，0 额外时延）
        │     证据打分表（附录 A）→ score ∈ [-6, +6]
        │     ├─ score ≥ +3  → P(addressed) 高 → 放行/正常响应
        │     ├─ score ≤ -3  → 判 S1（指向人）
        │     └─ 其余        → 档 B
        │
        ├─ 档 B｜小模型（文本分类器，≤40 ms）
        │     输入：文本 + 结构化特征（是否有称呼/谓词类型/是否承接/系统状态）
        │     输出：P(addressed) + 校准后的置信
        │     ├─ P < 0.3 且代价低 → silent_record
        │     ├─ P > 0.7          → 放行
        │     └─ 中间              → 档 C 或 clarify
        │
        └─ 档 C｜LLM 复核（异步，不阻塞静默决策）
              仅对"低置信 + 高代价"样本：含设备词但像转述、混合轮
              输出证据化结论 + 建议动作，用于下一轮阈值标定与错误分析

为什么这么分：档 A 覆盖 70%–80% 的清晰样本且可审计；档 B 处理同形与省略；档 C 处理"两解"与混合轮，并且永远不阻塞静默（异步）。

3.2 输入特征清单（档 B 用）

类别 特征 说明
称呼 是否含亲属称谓 / 人名 / 你们；称谓位置（句首/句中） 句首称呼更强
谓词 人—人谓词命中数、设备谓词命中数、二者共存 共存 → 混合轮嫌疑
人称 第一/第二/第三人称主语 "你"指向人；"小X"指向设备
衔接 与系统上一句的相似度、是否槽位补充、是否以"嗯/对/是的"开头 强 S0 信号
言语行为 是否转述（"他说/她说/它说"）、是否疑问索取信息 转述 → S1
状态 系统 idle / speaking；当前是否有待填槽位 与语义交叉
上下文 前 3 轮是否出现过该称呼、该物品 消解省略

3.3 与声学/空间的融合（late fusion，不做特征拼接）

P(addressed | sem, ac) ∝ P(sem | addressed) · P(ac | addressed) · P(addressed)
情形 语义 声学/空间 动作
一致指向人 指向人 朝向偏离设备 S1（高置信）
一致指向设备 指向设备 正面朝向设备 S0
冲突 指向人 正面朝向设备 S1 + 低置信标记（人可能侧头说话），评测单列
冲突 指向设备 明显偏离 clarify（不执行）
都缺失 低置信 无空间信号 silent_record（宁可少说）

纪律：声学置信只做先验调节，不做否决；语义也不否决唤醒词——唤醒词是硬规则（出现即 S0）。

3.4 校准与阈值

  • 温度缩放（temperature scaling）在小模型输出上做一次，避免"高置信但错"。
  • 阈值按场景分别标定：家庭音箱（远场、多成员）与手机（近场、单人为主）的 P 分布不同，不能共用一个阈值。
  • 输出必须带证据 JSON：{"scene":"S1","p":0.12,"evidence":["E1:妈","E2:递"],"rule":"A"}——用于审计与错误归因。

4. 十二个语义子场景（S1-SEM）

每个子场景都要有正例、易混反例、以及"该靠哪几类证据"。表里的"动作"是期望输出。

编号 子场景 判据（证据组合） 典型句 易混反例 动作
SEM1 称呼 + 人—人动作 E1 + E2 "妈，把盐递给我" "小X，把盐递给我"（→S0） silent_record
SEM2 同形命令（对家人复述） E3 + 无 E4 + 空间偏离 "把空调调到 26 度"（冲客厅说） 同句正对设备（→S0） silent_record
SEM3 指代递物 E5 + E2 "这个给我" "这个放桌上"（无前文，→clarify） silent_record
SEM4 家务协调 E2×2 + E1 或缺省 "你收衣服，我洗碗" "把洗衣机打开"（→S0） silent_record
SEM5 呼唤—应答 E7 "老张——""哎" "小X——"（→S0） silent_record
SEM6 转述/引用 E6（他说/她说）+ E3 "他说把灯关了" "把灯关了"（→S0） silent_record
SEM7 对第三人评论 E1/E6 + 无请求 "这孩子又不吃饭" "再放一遍"（→S0） silent_record
SEM8 电话/视频 E6 + 语境（通话中） "我一会儿回给你" "小X，帮我挂断"（→S0） silent_record
SEM9 儿童对家长 E1 + 儿童声线 "妈妈，我要喝水" "小X，讲故事"（→S0_guest） silent_record
SEM10 self-talk 临界 无 E1、无 E2、无 E4 "钥匙放哪儿了……" "老公，钥匙放哪儿了"（→S1） silent（不记）
SEM11 混合轮 E1 + E3 共存 "妈你等一下——小X 声音小点" 整句判 S1（错，会吞指令） 分段：前 S1 / 后 S0
SEM12 隐式指代（无称呼但对我说） E2 + E8（槽位待填） "放桌上就行"（回应"放哪儿"） 冷启动同句（→clarify） silent_record 或 clarify

SEM6 与 SEM11 是语义层唯一的两个"必须做对否则全盘皆输"的场景：前者是设备词出现在非指令里，后者是一句话里同时有人和设备。

5. 冲突消解：优先级与动作表

冲突 例子 规则 动作
唤醒词 vs 语义旁白 "小X，我妈说把灯关了" 唤醒优先（硬规则） S0（执行关灯）
承接系统 vs 指向人 系统问"要几度"，用户回头对家人说"26 度" 承接为强 S0 信号，但若同时命中 E1 → 降置信 S0 或 clarify
转述 vs 设备指令 "他说把灯关了" 转述一律 S1，哪怕含完整指令 silent_record
混合轮 "妈你等下——小X 声音小点" 按"——/，小X"切分，分段判定 前 S1 / 后 S0
语义 vs 空间 语义指向人，空间正面朝设备 语义优先，标低置信 S1（低置信）
全低置信 "把它关了吧" 不得静默吞掉 clarify

6. 用例覆盖：八组最小对 + 语义族矩阵

6.1 用"最小对"而不是"多造样本"

最小对（minimal pair）= 同一句话，只改一个决定受话人的变量。它直接回答"模型是在判对象，还是在判文本"。

配对 固定 只改 期望 检验
MP1 称呼 "把盐递给我" 加/去"妈，" 无称呼→?；有称呼→S1 称呼是否是主证据
MP2 称呼对象 "把盐递给我，___" 妈 / 小X S1 / S0 是否区分称谓与唤醒词
MP3 直述/转述 "把灯关了" 加"他说" S0 / S1 转述陷阱
MP4 承接 "26 度" 前有/无系统提问 S0 / 低置信 上下文依赖
MP5 谓词 "把递给我" / "把调到 26" 遥控器 / 空调 S1 / S0 人—人 vs 设备谓词
MP6 指代 "放桌上" 有/无前文指物 S1 / clarify 省略消解
MP7 混合轮 同句 切分点前/后 段1 S1 / 段2 S0 分段能力
MP8 隐式 "放那儿就行" 有/无待填槽位 S1 / S0 隐式指代

组量：每组 ≥ 50 对（即 100 条），八组共 800 条；配对判分用 pair accuracy（两条都对才计分）。

7. 怎么证明"语义层真的有用"（消融四组）

7.1 四组对照

组 配置 目的
A 仅声学/空间（无文本语义） 下限：证明"只靠声学在同形集上必然失败"
B 仅语义（无空间） 证明纯文本能走多远
C 语义 + 空间 late fusion 目标配置
D C + clarify 策略 证明"可逆降级"降低了误吞的代价

7.2 必须分开报的两个数

  • 全集 S1 拒识率（易被非同形样本抬高）
  • 同形子集拒识率（真正的难度所在）

若 C 相对 B 在同形集上没有提升 → 说明空间信号没起作用或特征被语义淹没；若 B 相对 A 提升很小 → 说明语义特征没抓对（先去查标注，而不是换模型）。

7.3 泄漏自检（语义层特有）

  1. 词表泄漏：训练 LR / n-gram 基线，F1 > 0.85 即说明"看到某个词就判"，同形样本不足。
  2. 称呼泄漏：S1 集里称呼词占比 vs S0 集——若 S0 几乎没有称呼，模型会学"有称呼=旁白"（真实场景里用户也会说"小X，妈让你关灯"）。
  3. 长度泄漏：S1 平均句长显著长于 S0 → 补短旁白。
  4. 说话人泄漏：S1 全由家人录、S0 全由机主录 → 必须同人。

8. 标注规范：不只标场景，要标"证据"

每条样本的标注字段：

{"id":"sem_mp3_0012","scene":"S1","subscene":"SEM6","action":"silent_record",
 "evidence":["E6","E3"],"conf":"H","isomorph":"full","pair_id":"MP3_012",
 "sys_state":"idle","speaker":"main","addressee":"person_spouse","text":"他说把灯关了"}
  • evidence 多选（E1–E8），必须至少标 1 个；标"无"说明该样本应有歧义（进 clarify 集）。
  • 双标 + 仲裁：场景 Kappa ≥ 0.75；证据 Kappa ≥ 0.65（证据比场景更难一致，这是可接受的）。
  • 两解样本：标"主解 + 次解"，主解计分，两解都对算软口径，单独报一个"软准确率"。

9. 错误类型学（用来做错误分析，不是用来写论文）

编号 类型 触发条件 检测方法 修法
FA1 称呼缺失型误响应 对家人说话但没称呼 混淆矩阵按 subscene 看 补 E2 谓词特征
FA2 转述型误响应 "他说把灯关了" 单独看 SEM6 子集 加转述规则
FA3 儿童声线 儿童对家长 按 speaker=child 切片 补儿童语料
FA4 媒体台词 电视里带指令 按音频源切片（应为 S4） 媒体检测前置
FA5 混合轮切分错 "…——小X…" 看 SEM11 切分规则 + 标点
FA6 隐式指代 "放那儿就行" 看 SEM12 槽位状态特征
FA7 方言称呼未识别 "阿妈""老娘" 按方言切片 称呼词典扩充

10. 两周落地清单

阶段 产出 验收
D1–D2 证据打分表（附录 A）+ 规则基线 v0 在同形集 ≥ 80%（规则基线不追求高，追求可解释）
D3–D5 500 条语义标注（含 8 组最小对的一半） 双标 Kappa ≥ 0.75
D6–D8 小模型 baseline（LR → 0.5B 微调） 同形集 ≥ 88%，混淆矩阵按 SEM 分层
